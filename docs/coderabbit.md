# CodeRabbit Setup

This repository includes `.coderabbit.yaml` for CodeRabbit configuration.

To enable automated CodeRabbit reviews:
1. Install the CodeRabbit GitHub App for your account/org.
2. Grant access to `Hsk4/Laptop_Harbour_App_Expo`.
3. Ensure PR events are enabled for the repository.

No secrets or tokens are committed in this repository for CodeRabbit.
